## Автоматизация тестирования API сайта "Самокат"

### Этот проект содержит автотесты для API сайта "Самокат" (https://qa-scooter.praktikum-services.ru/), написанные с использованием **Requests**, **Pytest**. 
### Тесты проверяют:
### • создание и удаление курьера;
### • авторизацию курьера;
### • создание заказа;
### • принятие заказа;
### • получение заказа по его номеру;
### • получение списка заказов.

## <h>Инструкция по запуску:</h>

### <h>1. Установите зависимости:</h>

> pip install -r requirements.txt</h>

### <h>2. Запустить все тесты и записать отчет:</h>

> pytest --alluredir=allure-results

### <h>3. Посмотреть отчет по прогону html</h>

> allure serve allure-results
